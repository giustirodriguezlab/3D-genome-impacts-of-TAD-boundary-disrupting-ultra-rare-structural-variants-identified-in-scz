# 3D-genome-impacts-of-TAD-boundary-disrupting-ultra-rare-structural-variants-identified-in-scz
We engineered two schizophrenia-associated TAD-boundary SVs in iPSCs and differentiated them into neuronal precursors, excitatory glutamatergic neurons, and medium spiny neurons. We found cell-type-specific changes in 3D genome structure linked to changes in gene expression.
